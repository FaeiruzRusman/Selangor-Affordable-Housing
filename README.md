# Selangor Affordable Housing Intelligence Dashboard

Prototype dashboard untuk pemantauan Perumahan Mampu Milik Negeri Selangor di bawah kerangka Selangor Urban Observatory (SUO).

## Kandungan Utama

- Executive KPI
- Housing Scheme Portfolio
- Spatial Distribution & Housing Pressure Map
- Supply vs Demand by District
- Project Delivery Status
- Affordability Intelligence
- Project Monitoring Register
- Decision Support Layer

## Housing Schemes

- Rumah Selangorku
- Rumah Idaman Selangor
- Smart Sewa
- PPR

## Cara Deploy ke GitHub Pages

1. Upload semua fail repository ini ke GitHub.
2. Pastikan fail utama bernama `index.html` berada di root repository.
3. Pergi ke **Settings > Pages**.
4. Di bahagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Klik **Save**.
7. GitHub akan jana URL GitHub Pages untuk dashboard ini.

## Nota Data

Prototype ini menggunakan beberapa KPI rasmi peringkat negeri yang tersedia semasa pembangunan dashboard. Data pecahan daerah, koordinat dan beberapa rekod peta masih merupakan data demo dan perlu digantikan dengan dataset rasmi LPHS/SUO sebelum digunakan sebagai dashboard produksi.
